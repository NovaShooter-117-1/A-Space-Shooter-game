    How to install
    1. If your download ends in .mcaddon.zip, rename it to end in .mcaddon. Pack ZIPs can be renamed to .mcpack.
    2. Open the file with Minecraft Bedrock to import it.
    3. Enable both the Resource Pack and the Behavior Pack on your world. If the disc is missing, also turn on the world’s Experiments.
    4. Run the /give command above, put the disc in a jukebox, and listen.
